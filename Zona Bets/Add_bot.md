How people add the bot to their server:

You generate an invite link from the Discord Developer Portal:

Go to discord.com/developers/applications and select your bot
Click OAuth2 → URL Generator in the left sidebar
Under Scopes, check bot
Under Bot Permissions, check what your bot needs:
Read Messages / View Channels
Send Messages
Create Public Threads
Send Messages in Threads
Add Reactions
Manage Messages (optional — lets the bot remove invalid reactions)
Copy the generated URL at the bottom and share it
Anyone with Manage Server permissions in a Discord server can open that link and add the bot to their server. That's the standard way Discord bots are distributed.
