# Hyperagent

An agent platform Ian uses for prospecting and productized offers for [[mirk-technologies]].

- **Lead prospecting agent**: a system prompt plus task prompts that find East Valley home-service businesses, score automation gaps and draft emails in Ian's voice ([[Lead prospecting with Outreach]]). Output example: ![[Hyperagent Agent Kit - Quick Revenue Wins.html]] ([[html output]]).
- **Gap scoring**: 2 pts each for no chat, no online booking, review response under 50%, missed-call complaints; 1 pt each for no SMS CTA, outdated site. The highest-scoring gap picks the email angle ([[Signal Checklist]]).
- **Offer idea**: a low-ticket "24-Hour Premium Listing Kit" for real estate agents, built from Zillow/Redfin listings in the $400k–700k range ([[Low-Ticket "Cinematic Real Estate Listing" Kits]]).
